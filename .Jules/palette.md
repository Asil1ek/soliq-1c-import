## 2026-11-01 - Accessible Focus States for Visually Hidden File Inputs
**Learning:** In this application, file inputs are visually hidden (`opacity: 0`) and stretched over a custom styled upload card to allow drag-and-drop and click interactions. Because they are native `<input type="file">` elements, they still receive keyboard focus during tab navigation. However, since they are invisible, users navigating via keyboard have no visual indication of which input has focus.
**Action:** Used the existing hover/drag CSS class (`.dragover`) on the parent card to serve as a visible focus indicator. This is toggled via inline `onfocus` and `onblur` events on the file input, providing keyboard accessibility without adding custom CSS. Added ARIA labels in Uzbek for screen reader support.
